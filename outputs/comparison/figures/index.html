Methodology and data scope

Fixed prompt v1 and threshold 0.5; only v1 is shown. The main charts give equal weight to six jointly tested non-PII datasets. The two PII datasets are summarized separately, and the eight-dataset averages are supplementary only. AUROC is undefined for both the PII and all-eight-dataset scopes and remains N/A. Average Accuracy, Precision, Recall, F1, AUROC and latency are shown. Only dataset names are shared; successful samples are not aligned across models, so these results must not be ranked together with the original sample-aligned model averages. Quality averages retain the full shared dataset scope; a missing metric on any dataset makes that average N/A. Latency gives equal weight to the shared subset with available timing for every model; the figure states its scope and count. Latency is N/A only when no shared timing subset exists; datasets are never dropped separately for individual models. The three APIs use single-run v1 / 0.5 logs, without substituting other thresholds or four-run averages. OpenJev 4B retains supplied summary timing; 32B and Decision-1 use supplied single-run timing. Protocols differ, so timing is reference-only. 32B's ToxiGen metrics are now complete and included normally in quality averages. All six metrics are visible in two columns and three rows: Accuracy / F1, Precision / Recall, AUROC / Latency. Narrow screens use one column; the shared model color legend appears at the top.

Prompt and Threshold Sensitivity (Fastino, Laya, TypeSafe)

Colors identify models; solid lines with circles indicate v1, and dashed lines with triangles indicate v2. Filled markers use shared successful samples at the same configuration. When paired metrics are unavailable, hollow markers show the model's own successful samples, so missing results from another model do not hide available measurements. Missing or all-failed configurations remain gaps, without zero-filling or interpolation. Sample sets may differ across points; this is not a fair ranking. Each threshold requires a new model call, so the curves mix threshold effects with repeat-call variation rather than isolating threshold effects on fixed scores. This is exploration on the same test set, not an independently validated performance improvement.
